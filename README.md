# LMS Platform

Django REST Framework API для образовательной платформы с курсами и уроками.

## Функциональность

- **Пользователи** - кастомная модель с авторизацией по email
- **Курсы** - управление образовательными курсами (CRUD через ViewSet)
- **Уроки** - управление уроками в рамках курсов (CRUD через Generic-классы)

## Модели

### Пользователь (User)
- Авторизация по email вместо username
- Телефон, город, аватарка
- Кастомная модель в приложении `users`

### Курс (Course)
- Название, описание, превью-изображение
- Связь "один-ко-многим" с уроками

### Урок (Lessons)  
- Название, описание, превью-изображение
- Ссылка на видео
- Принадлежность к курсу (ForeignKey)

## API Endpoints

### Курсы
- `GET/POST /course/` - список и создание курсов
- `GET/PUT/DELETE /course/{id}/` - детали, обновление, удаление

### Уроки
- `GET /lesson/` - список всех уроков
- `POST /lesson/create` - создание урока
- `GET /lesson/{id}` - детали урока
- `PUT /lesson/update/{id}` - обновление урока  
- `DELETE /lesson/delete/{id}` - удаление урока


## Установка

1. Клонировать репозиторий
2. Настроить базу данных в `.env`
3. Выполнить миграции: `python manage.py migrate`
4. Запустить сервер: `python manage.py runserver`

## Особенности реализации

- ViewSet для курсов
- Generic-классы для уроков  
- Простейшие ModelSerializers
- Готова для тестирования в Postman
