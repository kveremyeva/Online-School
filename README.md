# LMS Platform

Django REST Framework API для образовательной платформы с курсами и уроками.

## Функциональность

- **Пользователи** - кастомная модель с авторизацией по email
- **Курсы** - управление образовательными курсами (CRUD через ViewSet)
- **Уроки** - управление уроками в рамках курсов (CRUD через Generic-классы)

## Модели

### Пользователь (User)
- Авторизация по email вместо username
- Телефон, город, аватарка
- Кастомная модель в приложении `users`

### Платежи (Payment)
- Связь "многие-к-одному" с пользователями, курсами и уроками
- Платеж может быть привязан либо к курсу, либо к уроку (или к обоим)
- Валидация суммы (только положительные числа)
- Выбор способа оплаты из предопределенных вариантов

### Курс (Course)
- Название, описание, превью-изображение
- Связь "один-ко-многим" с уроками

### Урок (Lessons)  
- Название, описание, превью-изображение
- Ссылка на видео
- Принадлежность к курсу (ForeignKey)

## API Endpoints

### Курсы
- `GET/POST /course/` - список и создание курсов
- `GET/PUT/DELETE /course/{id}/` - детали, обновление, удаление

### Уроки
- `GET /lesson/` - список всех уроков
- `POST /lesson/create` - создание урока
- `GET /lesson/{id}` - детали урока
- `PUT /lesson/update/{id}` - обновление урока  
- `DELETE /lesson/delete/{id}` - удаление урока

### Фильтрация вывода списка платежей:
* менять порядок сортировки по дате оплаты,
* фильтровать по курсу или уроку,
* фильтровать по способу оплаты.


#### Сортировка по дате оплаты:
```
GET /users/payments/?ordering=date_pay        # по возрастанию
GET /users/payments/?ordering=-date_pay       # по убыванию
```
#### Фильтрация по способу оплаты:
```
GET /users/payments/?method_pay=cash          # только наличные
GET /users/payments/?method_pay=transfer      # только переводы
```
#### Фильтрация по курсу и уроку:
```
GET /users/payments/?course=1                 # платежи за курс 1
GET /users/payments/?lessons=5                # платежи за урок 5
```

## Установка

1. Клонировать репозиторий
2. Настроить базу данных в `.env`
3. Выполнить миграции: `python manage.py migrate`
4. Запустить сервер: `python manage.py runserver`
5. Импорт данных из фикстуры: `python manage.py loaddata payment_fixture.json`

## Особенности реализации

- ViewSet для курсов
- Generic-классы для уроков  
- Простейшие ModelSerializers
- Готова для тестирования в Postman
